# Related Projects in Geospatial Data & Health

EnVar is part of a broader portfolio of [TISLab](https://tislab.org/) projects that connect geospatial environmental data with health outcomes. These projects overlap and reinforce each other — shared participants, shared infrastructure, and shared goals around environmental data standardization.

## How They Connect

The projects form a network of complementary efforts:

- The **OHDSI GIS WG** provides the core infrastructure (Gaia toolchain, OMOP `external_exposure` table) that other projects build on
- **HIV & Climate Change** is a concrete use case that exercises the GIS WG infrastructure
- **Geodata 4 Health** develops the data standards (environmental CDEs, geolocation standards) needed across all projects
- **CLAD** provides real-world data linkage for All of Us and inspired the Geodata 4 Health collaboration area
- **Microschema** provides the technical specification framework for CDEs used by EnVar and others
- **EnVar** synthesizes these efforts into formal environmental CDEs and OMOP guidelines
- **BioData Catalyst** extends the approach to the BDC ecosystem
