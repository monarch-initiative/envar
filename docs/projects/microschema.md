# Microschema

## Goal

Create [LinkML](https://linkml.io/) schemas for NIH CDEs. Most NIH CDEs are under-specified from a technical perspective. Microschema provides a formal, machine-readable specification that captures the full context of a CDE.

## Repositories

- [linkml-microschema-profile](https://github.com/linkml/linkml-microschema-profile) — core schema in the LinkML organization
- Clinical measurement microschema — created by Anne with examples

## Status

Recently started. Microschema makes use of LinkML rules and expressions that have not yet been fully developed.

## Broader Applicability

Microschema can be used across many disciplines, not just for biomedicine or NIH CDEs. Anne plans to:

- Create environmental CDEs using this specification
- Use microschema in the context of [BioData Catalyst](bdc-dmc.md), with the goal that CDEs in the harmonized CDE repository will be microschema-compliant

## Connections
