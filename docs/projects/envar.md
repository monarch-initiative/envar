# EnVar

!!! info
    This page describes **EnVar** — the project formerly tracked internally as the "NIEHS Enviro CDE Project". The goals below are the formal objectives of the EnVar effort.

## Goal

Create environmental CDEs and guidelines for getting environmental data into an OMOP record.

## Status

Active. One-year project duration starting April 1, 2026.
