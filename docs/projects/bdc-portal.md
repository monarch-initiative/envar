# BioData Catalyst Data Portal

## Goal

Build tools and services for a [BioData Catalyst](https://biodatacatalyst.nhlbi.nih.gov/) data portal that includes a way for users to view and interact with geospatial data.

## Status

Not yet started. Will depend on bringing geospatial data into BDC first (see [BDC DMC](bdc-dmc.md)).

## Lead

TISLab is leading the construction of tools and services for this portal.

## Connections

- Depends on geospatial data capacity built by the [BDC DMC](bdc-dmc.md) project
- Will benefit from data standards developed in [Geodata 4 Health](geodata4health.md)
